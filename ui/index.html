🔧 Quick start

🔒 Single source of truth: VPS environment variables.

All credentials live in your VPS / Coolify env panel. Nothing on this dashboard can change them — only redeploys can.

  1. Open Supabase → SQL Editor → paste the contents of supabase_schema.sql → run.
  2. On your VPS / Coolify panel, set the env vars listed in .env.example: LiveKit, Gemini, Supabase, Vobiz, etc.
  3. Deploy the container (docker run or Coolify auto-deploy).
  4. Open ⚙️ Settings → verify all required env vars show ✓ set.
  5. If you don't have a SIP trunk yet, click ⚡ Create SIP Trunk in LiveKit and copy the returned ID into your VPS env as OUTBOUND_TRUNK_ID → redeploy.
  6. Open ✏️ AI Prompt → customise for your business → Save (this is app state, persists in Supabase).
  7. Open 🤖 Agents → create at least one agent profile.
  8. Open 📞 Single Call → call your own phone to verify everything works.
